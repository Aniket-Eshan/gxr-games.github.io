# Introduction
### This repository is a personal project focused on experimenting with web design and game site development. It includes a spoof blocker and a game launcher, among other features.

# Features
### Game Site: Visit bit.ly/supernovafx to explore a collection of games. The homepage features a stylized constellation header and buttons that link directly to playable titles. You can also check out the alternate site at bit.ly/supernovagx for more games.
### Blocker: Navigate to supernova-fx.github.io/blocker.html to try the spoof blocker. Type any URL or name into the input box and click “Launch.” It will display a Linewize blocked page using your input. This is purely for entertainment and does not perform any real blocking.
